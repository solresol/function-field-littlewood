# Root-moment rigidity for the Lai–Sprang Littlewood series in Lean 4

Version 0.1.0, 3 October 2026. Research software by Greg Baker.

Version DOI: `10.5281/zenodo.23117611`, reserved for this source snapshot;
the identifier is registered when the Zenodo deposit is published.

## What this release proves in Lean

The principal new result is
`FunctionFieldLittlewood.ParityDescent.geometric_parity_forced_factor` in
`FunctionFieldLittlewood/ParityDescent.lean`.

Let p>2 be prime, H>0, p-1=2H(2k+1), and let z_0,...,z_(H-1) be distinct
elements of F_p satisfying z_i^H=-1. For s dividing H put

    g(t) = sum_(a=0)^(H/s-1) t^(sa).

Given polynomials U_0,U_1 and n>=0, assume the H moment equations

    sum_i z_i^(n+j) g(z_i) (U_0(z_i)^2-z_i U_1(z_i)^2) = 0
        for j=0,...,H-1.

Lean proves that t^H+1 divides both U_0 and U_1 and that g(t)(t^H+1)
divides both gU_0 and gU_1. The proof derives the needed nonsquareness,
geometric-factor nonvanishing and polynomial divisibility; they are not
assumed conclusions. The root enumeration and moment equations are explicit
hypotheses. An F_5 instance and a counterexample to dropping a moment are
also checked.

The release includes the earlier exact-certificate and dual-certificate
soundness results, polynomial normalisation, named support streams,
Laurent coefficient identities, and strictly positive fractional-part/product
bridges. Detailed statements and audit records are in the dated `results/`
reports, especially `2026-10-03-moment-rigidity.md`.

## Scope of the mathematical claim

The method adapts Lai–Sprang, arXiv:2606.00633v1, Section 3. Their theorem
already supplies counterexamples in all odd characteristics.

The included ordinary parity-descent proof establishes the auxiliary bound
j-d<=N at every shift for d<N(N-1), where N=2^v_2(p-1). The derivation of
the moments from a parent coefficient window, uniform root enumeration,
degree/shift bookkeeping and complete descent iteration are not yet assembled
into a Lean proof of that cutoff. This release makes no all-degree N-bound,
characteristic-two counterexample, first-formalisation or peer-review claim.

## Reproduction

Requirements: elan/Lake, Git and Python 3.9 or later. The source archive
contains no `.lake` directory or Git history. In its extracted root run:

```sh
lake exe cache get
lake build
python3 -m unittest discover -s tests -v
python3 -m search.lai_sprang_descent_check
```

Lean and mathlib are pinned to v4.27.0; `lake-manifest.json` pins the precise
dependency commits, including mathlib
`a3a10db0e9d66acbebf76c5e6a135066525ac900`.
The root module includes the theorem dependency audits. Only `propext`,
`Classical.choice` and `Quot.sound` are permitted in the completed results.
Exact finite experiments are validation and do not prove universal statements.
